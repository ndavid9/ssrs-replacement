Northline layout studio

Report types

Food Export, Water Compliance, and Internal QC are examples. Each type chooses its own sections. Nothing here is a real certificate.

Domain schema

Multiplicities are fixed. A report type decides which of these domains are included, not a new relationship.

Nordic report shapes — vertical rows, grouped tests, sample columns, footnotes, and limits — live in the separate Nordic examples tab. That sandbox does not change this editor.

Layout for this report type

Drag a card or use Move up / Move down. Included sections print. Required sections may not be turned off. Feeds stay on the named contracts shown in the schema.
